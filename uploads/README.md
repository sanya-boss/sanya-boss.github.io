# Sanya CV — проект для Claude Design

Это готовый статический сайт без сборщика и зависимостей.

## Как открыть в Claude Design

1. Загрузите архив `sanya-cv-claude-design.zip` в Claude.
2. Попросите открыть проект и редактировать `index.html`.
3. Если интерфейс не принимает ZIP, распакуйте архив и загрузите оба файла проекта вместе.

## Файлы

- `index.html` — вся разметка, стили и JavaScript сайта.
- `aleksandr-portrait.webp` — оптимизированная фотография.

Для фонового YouTube-видео и веб-шрифтов при просмотре нужен интернет. Локально сайт можно открыть двойным кликом по `index.html`.
